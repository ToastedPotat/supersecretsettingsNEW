# About SSSN
Basically it aims to take the old 25 (or 26 considering Blit) super-secret-settings in the new Minecraft (after 26.3)
Some of them are already present in the game (5 to be precise)
So the other 20 have been removed, and i want to give them new life
The effects are many and my basical roadmap is:
- during Alpha release: complete the easier 5 effects
- during Beta release: complete the less-easy effects (in the end abt 17 total effects)
- during Pre-release: complete the hard 3 effects
- during Full release: 2 extra vanilla effects (maybe)

I have not used any AI code
